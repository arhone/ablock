# Документация для агентов

Устойчивые знания о проекте: устройство, как проверять, решения автора, которые действуют надолго. Временное (ход задач, память воркеров) — не сюда, а в `.agents/tasks` и `.agents/workers`.

Описание для людей — `README.md` в корне: возможности, окно, оценка сайта, структура `src/`, правила, списки фильтров, переводы, сборка. Здесь — только то, чего там нет.

## Разделы
- `checking.md` — как проверять изменения: линтеры, headless Chrome, что смотреть в окне.
- `decisions.md` — решения автора, которые действуют надолго.
