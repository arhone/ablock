# Решения автора

Действуют, пока автор не скажет иначе. Дата — когда принято.

## Продукт
- Только Chrome и Яндекс Браузер (Яндекс ставит из Chrome Web Store). Edge, Opera, Firefox не предлагать: Edge не дал аккаунт, Opera не открывается, Firefox отложен (AMO требует `background.scripts` и `gecko.id` — если вернутся, отдельным манифестом в `tools/pack.sh`). 2026-10-28.
- Данные не покидают браузер. Новых запросов к сайту (ads.txt, sitemap.xml, http-версия, HEAD для canonical) — скорее не нужно. 2026-10-28.
- Не делать: устаревшие версии библиотек (это поиск уязвимостей), axe-core, разрешения `debugger` и `cookies`. 2026-10-28.
- В промо и на скриншотах — без Meta; показывать технологии и компании, которые автор хочет показать: Angie, Yandex, DDoS-Guard и т. п. 2026-10-27.

## Окно
- Оценка сайта — по группам с весами 3/2/2/1/1 (приватность, скорость, безопасность, SEO, доступность), «Роботы и ИИ» без балла; таблица — README «Оценка сайта». 2026-10-28.
- Область оповещений — одна карточка за раз: оценить (30 дней после установки) → поддержать (90 дней после закрытия «Оценить», один раз) → «Расширенный режим» → статистика. 2026-10-28.
- Подпись на картинке отчёта — адрес сайта ablock.arh.one, когда он заработает (до этого `github.com/arhone/ablock`). 2026-10-29.

## Процесс
- Изменения — в CHANGELOG «Не выпущено», версию ставит автор. alpha → main сливает автор после проверки в браузере.
