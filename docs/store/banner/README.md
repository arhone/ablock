# Баннеры README и превью GitHub

`ru.html` и `en.html` — непрозрачные баннеры 1280×640. Общий CSS импортирует
`docs/site/site.css`, фиксирует светлую палитру и размеры. Используются системные
шрифты сайта, локальные логотип, фон и настоящие отчёты «Поделиться» о ya.ru.
Внешних ресурсов нет; CSP запрещает сетевые запросы.

Из корня репозитория, Node.js 20.19+ и установленный Google Chrome:

```sh
node docs/store/banner/capture.mjs
```

Для этого worktree точная команда из любой папки:

```sh
node /srv/arhone/ablock.wt/readme-promo/docs/store/banner/capture.mjs
```

`CHROME=/путь/к/google-chrome` задаёт исполняемый файл. Если запуск от root требует
отключить sandbox, это можно явно сделать через `NO_SANDBOX=1`.
Скрипт не требует npm-пакетов, использует CDP `--remote-debugging-pipe`, временный
профиль и локальные `file:` URL. HTTP(S) в странице заблокированы. Ждёт загрузки
картинок и шрифтов, проверяет геометрию, создаёт в `docs/img/`:

- `banner-ru.webp`, `banner-en.webp` — картинки README;
- `banner-ru.png`, `banner-en.png` — превью GitHub, каждое не больше 1 000 000 байт.

При превышении размера или выходе блоков за кадр завершится с ошибкой.
Перед публикацией просмотреть оба языка: заголовок и тезисы слева, полный отчёт
справа, ничего не обрезано. PNG загрузить в настройках репозитория GitHub
в поле Social preview (это ручная настройка, README её не меняет).

Снимки делает оркестратор вне песочницы.

## Open Graph для сайта

`og-ru.html`, `og-en.html`, `og-es.html`, `og-pt-br.html`, `og-de.html` и общий
`og.css` — отдельные превью 1200×630. Заголовок, описание и тезис о бесплатности
взяты с первого экрана соответствующего языка сайта. Справа — настоящий отчёт
ya.ru на том же языке. Стили, логотип, фон и отчёты локальные; CSP запрещает
внешние ресурсы. Используются системные шрифты сайта.

Снять только пять OG-превью (из любой папки):

```sh
node /srv/arhone/ablock.wt/readme-promo/docs/store/banner/capture.mjs og
```

Результаты: `docs/site/img/og-ru.png`, `og-en.png`, `og-es.png`, `og-pt-br.png`,
`og-de.png`, каждое 1200×630 и не больше 1 000 000 байт. На эти абсолютные URL
ссылаются Open Graph и Twitter Card в index.html и privacy.html пяти языков.
PNG создаст оркестратор вне песочницы; перед публикацией нужно просмотреть все
пять картинок и убедиться в читаемости и отсутствии обрезки.

`capture.mjs readme` снимает только прежние баннеры README 1280×640.
Без аргумента (или с `all`) скрипт снимает и README, и OG. Переменные `CHROME`
и `NO_SANDBOX` работают во всех режимах. Скрипт проверяет размеры и границы
блоков для каждого формата, ждёт загрузки изображений и шрифтов; лимит PNG
применяется к каждой картинке отдельно.
