# ABlock - 広告ブロッカー＆サイトチェック

Название и краткое описание берутся из `src/_locales/ja/messages.json` (`extName`, `extDescription`), в консоли не вводятся.
В консоль вставляется текст из блока «Описание»; скриншоты — `../img/en/`.

**Название:** ABlock - 広告ブロッカー＆サイトチェック

**Краткое описание:** 広告とトラッカーをブロックして、ページを速く軽く。あらゆるサイトの速度・セキュリティ・追跡をチェックします。

## Описание

```text
ABlock は広告とトラッカーをブロックし、開いているサイトがどれだけ速く安全か、そこで誰があなたを追跡しているかをワンクリックで表示します。

より速く、より軽く
広告スクリプトやトラッカーがなければ、ページの読み込みが速くなり、モバイルデータやバッテリーの消費も減ります。ブロックはブラウザ自体が行うため、拡張機能が動作を遅くすることはありません。

より安全に
• 既知の詐欺サイト、フィッシングサイト、マルウェアサイトをブロックします。
• Cookie の同意ポップアップを非表示にします。
• お使いの言語に合わせて地域別フィルターリストが自動で有効になります。

サイトチェック
• 10 点満点の評価：速度、ページの重さ、セキュリティ、プライバシー。
• ページでデータを収集しているのは誰か、何がブロックされたか。
• HTTPS、セキュリティヘッダー、使用技術、ホスティング。
• レポートを画像またはテキストで共有。

プライバシー
すべてがブラウザ内で動作します。アナリティクスなし、アカウントなし、独自サーバーなし。

サイトが正しく動かない場合は、そのサイトだけ保護をオフにしてください。
```
