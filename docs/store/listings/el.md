# ABlock - Αποκλεισμός διαφημίσεων και έλεγχος σελίδων

Название и краткое описание берутся из `src/_locales/el/messages.json` (`extName`, `extDescription`), в консоли не вводятся.
В консоль вставляется текст из блока «Описание»; скриншоты — `../img/en/`.

**Название:** ABlock - Αποκλεισμός διαφημίσεων και έλεγχος σελίδων

**Краткое описание:** Αποκλείει διαφημίσεις και ιχνηλάτες: ταχύτερες σελίδες, λιγότερα δεδομένα. Ελέγχει ταχύτητα, ασφάλεια και παρακολούθηση.
