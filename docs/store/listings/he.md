# ABlock - חוסם פרסומות ובדיקת אתרים

Название и краткое описание берутся из `src/_locales/he/messages.json` (`extName`, `extDescription`), в консоли не вводятся.
В консоль вставляется текст из блока «Описание»; скриншоты — `../img/en/`.

**Название:** ABlock - חוסם פרסומות ובדיקת אתרים

**Краткое описание:** חוסם פרסומות ורכיבי מעקב: דפים מהירים יותר ופחות נתונים. בודק מהירות, אבטחה ומעקב בכל אתר.

## Описание

```text
ABlock חוסם פרסומות ורכיבי מעקב ומראה בלחיצה אחת עד כמה האתר שבו אתם נמצאים מהיר ובטוח, ומי עוקב אחריכם בו.

מהיר וקל יותר
בלי סקריפטים של פרסומות ורכיבי מעקב, הדפים נטענים מהר יותר וצורכים פחות נתונים סלולריים וסוללה. הדפדפן עצמו מבצע את החסימה, כך שהתוסף לא מאט שום דבר.

בטוח יותר
• חוסם אתרי הונאה, פישינג ונוזקות מוכרים.
• מסתיר חלונות הסכמה לעוגיות.
• רשימות סינון אזוריות מופעלות אוטומטית לפי השפות שלכם.

בדיקת אתר
• ציון מתוך 10: מהירות, משקל הדף, אבטחה ופרטיות.
• מי אוסף נתונים בדף ומה נחסם.
• HTTPS, כותרות אבטחה, טכנולוגיות ואחסון.
• שיתוף הדוח כתמונה או כטקסט.

פרטיות
הכול פועל בתוך הדפדפן שלכם. בלי אנליטיקה, בלי חשבונות, בלי שרתים משלנו.

אם אתר מסוים מפסיק לעבוד, כבו את ההגנה רק עבורו.

קוד פתוח: https://github.com/arhone/ablock
משוב: https://github.com/arhone/ablock/issues
תמיכה בפרויקט: https://boosty.to/a.arh/donate
```
