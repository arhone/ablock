# ABlock - Ad Blocker at Pagsuri ng Site

Название и краткое описание берутся из `src/_locales/fil/messages.json` (`extName`, `extDescription`), в консоли не вводятся.
В консоль вставляется текст из блока «Описание»; скриншоты — `../img/en/`.

**Название:** ABlock - Ad Blocker at Pagsuri ng Site

**Краткое описание:** Hinaharang ang mga ad at tracker: mas mabilis na page, tipid sa data. Sinusuri ang bilis, seguridad at pag-track ng anumang site.

## Описание

```text
Hinaharangan ng ABlock ang mga ad at tracker at ipinapakita, sa isang click, kung gaano kabilis at kaligtas ang site na binubuksan mo at kung sino ang sumusubaybay sa iyo roon.

MAS MABILIS AT MAS MAGAAN
Kapag walang ad script at tracker, mas mabilis mag-load ang mga page at mas kaunti ang nagagamit na mobile data at baterya. Ang browser mismo ang nagba-block, kaya walang pinapabagal ang extension.

MAS LIGTAS
• Bina-block ang mga kilalang scam, phishing at malware na site.
• Itinatago ang mga pop-up ng pahintulot sa cookie.
• Awtomatikong binubuksan ang mga panrehiyong filter list para sa mga wika mo.

PAGSURI SA SITE
• Marka mula 10: bilis, bigat ng page, seguridad at privacy.
• Sino ang nangongolekta ng data sa page at ano ang na-block.
• HTTPS, mga security header, teknolohiya at hosting.
• Ibahagi ang ulat bilang larawan o teksto.

PRIVACY
Lahat ay tumatakbo sa browser mo. Walang analytics, walang account, walang sariling server.

Kung masira ang isang site, i-off ang proteksyon para sa site na iyon lang.

Open source: https://github.com/arhone/ablock
Feedback: https://github.com/arhone/ablock/issues
Suportahan ang proyekto: https://boosty.to/a.arh/donate
```
