# ABlock - 广告拦截与网站检测

Название и краткое описание берутся из `src/_locales/zh_CN/messages.json` (`extName`, `extDescription`), в консоли не вводятся.
В консоль вставляется текст из блока «Описание»; скриншоты — `../img/en/`.

**Название:** ABlock - 广告拦截与网站检测

**Краткое описание:** 拦截广告和跟踪器，网页加载更快、更省流量。检测任意网站的速度、安全性和跟踪情况。

## Описание

```text
ABlock 拦截广告和跟踪器，一键查看网站有多快、多安全，以及谁在跟踪你。

更快、更省流量
没有广告脚本和跟踪器，网页加载更快，更省移动流量和电量。拦截由浏览器本身完成，扩展不会拖慢任何网页。

更安全
• 拦截已知的诈骗、钓鱼和恶意网站。
• 隐藏 Cookie 同意弹窗。
• 根据浏览器语言自动启用地区过滤列表。

网站检测
• 10 分制评分：速度、页面大小、安全性和隐私。
• 谁在页面上收集数据，拦截了什么。
• HTTPS、安全标头、所用技术和托管服务商。
• 可将报告以图片或文字分享。

隐私
一切都在浏览器中运行。没有统计分析，没有账号，没有自己的服务器。

如果某个网站显示异常，可以只在该网站上关闭保护。

开源代码：https://github.com/arhone/ablock
反馈：https://github.com/arhone/ablock/issues
赞助项目：https://boosty.to/a.arh/donate
```
