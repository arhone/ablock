# ABlock - Annonsblockerare och webbplatskoll

Название и краткое описание берутся из `src/_locales/sv/messages.json` (`extName`, `extDescription`), в консоли не вводятся.
В консоль вставляется текст из блока «Описание»; скриншоты — `../img/en/`.

**Название:** ABlock - Annonsblockerare och webbplatskoll

**Краткое описание:** Blockerar annonser och spårare: snabbare sidor, mindre data. Kontrollerar hastighet, säkerhet och spårning på alla webbplatser.

## Описание

```text
ABlock blockerar annonser och spårare och visar med ett klick hur snabb och säker webbplatsen du är på är, och vem som spårar dig där.

SNABBARE OCH LÄTTARE
Utan annonsskript och spårare laddas sidor snabbare och drar mindre mobildata och batteri. Det är webbläsaren själv som blockerar, så tillägget gör ingenting långsammare.

SÄKRARE
• Blockerar kända bedrägeri-, nätfiske- och skadeprogramsajter.
• Döljer cookie-banners.
• Regionala filterlistor slås på automatiskt för dina språk.

WEBBPLATSKOLL
• Betyg av 10: hastighet, sidvikt, säkerhet och integritet.
• Vem som samlar in data på sidan och vad som blockerades.
• HTTPS, säkerhetsrubriker, tekniker och webbhotell.
• Dela rapporten som bild eller text.

INTEGRITET
Allt körs i din webbläsare. Ingen analys, inga konton, inga egna servrar.

Om en webbplats slutar fungera kan du stänga av skyddet bara för den.

Öppen källkod: https://github.com/arhone/ablock
Feedback: https://github.com/arhone/ablock/issues
Stöd projektet: https://boosty.to/a.arh/donate
```
