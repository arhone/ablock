# ABlock - บล็อกโฆษณาและตรวจเว็บไซต์

Название и краткое описание берутся из `src/_locales/th/messages.json` (`extName`, `extDescription`), в консоли не вводятся.
В консоль вставляется текст из блока «Описание»; скриншоты — `../img/en/`.

**Название:** ABlock - บล็อกโฆษณาและตรวจเว็บไซต์

**Краткое описание:** บล็อกโฆษณาและตัวติดตาม หน้าเว็บโหลดเร็วขึ้นและใช้เน็ตน้อยลง ตรวจความเร็ว ความปลอดภัย และการติดตามของทุกเว็บไซต์

## Описание

```text
ABlock บล็อกโฆษณาและตัวติดตาม และแสดงให้เห็นในคลิกเดียวว่าเว็บไซต์ที่คุณเปิดอยู่เร็วและปลอดภัยแค่ไหน และใครกำลังติดตามคุณอยู่

เร็วขึ้นและเบาขึ้น
เมื่อไม่มีสคริปต์โฆษณาและตัวติดตาม หน้าเว็บจะโหลดเร็วขึ้น ใช้อินเทอร์เน็ตมือถือและแบตเตอรี่น้อยลง การบล็อกทำโดยเบราว์เซอร์เอง ส่วนขยายจึงไม่ทำให้อะไรช้าลง

ปลอดภัยขึ้น
• บล็อกเว็บไซต์หลอกลวง ฟิชชิง และมัลแวร์ที่รู้จัก
• ซ่อนหน้าต่างขอความยินยอมคุกกี้
• รายการตัวกรองตามภูมิภาคเปิดใช้โดยอัตโนมัติสำหรับภาษาของคุณ

ตรวจสอบเว็บไซต์
• คะแนนเต็ม 10: ความเร็ว ขนาดหน้าเว็บ ความปลอดภัย และความเป็นส่วนตัว
• ใครเก็บข้อมูลบนหน้าเว็บ และอะไรถูกบล็อกไปแล้ว
• HTTPS, ส่วนหัวความปลอดภัย, เทคโนโลยี และโฮสติ้ง
• แชร์รายงานเป็นรูปภาพหรือข้อความ

ความเป็นส่วนตัว
ทุกอย่างทำงานในเบราว์เซอร์ของคุณ ไม่มีการวิเคราะห์ ไม่มีบัญชี ไม่มีเซิร์ฟเวอร์ของเราเอง

หากเว็บไซต์ใดใช้งานไม่ได้ ให้ปิดการป้องกันเฉพาะเว็บไซต์นั้น
```
