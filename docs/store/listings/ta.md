# ABlock - விளம்பரத் தடுப்பான், தளச் சோதனை

Название и краткое описание берутся из `src/_locales/ta/messages.json` (`extName`, `extDescription`), в консоли не вводятся.
В консоль вставляется текст из блока «Описание»; скриншоты — `../img/en/`.

**Название:** ABlock - விளம்பரத் தடுப்பான், தளச் சோதனை

**Краткое описание:** விளம்பரங்களையும் டிராக்கர்களையும் தடுக்கிறது: பக்கங்கள் வேகம், டேட்டா குறைவு. எந்தத் தளத்தின் வேகம், பாதுகாப்பையும் சோதிக்கும்.

## Описание

```text
ABlock விளம்பரங்களையும் டிராக்கர்களையும் தடுக்கிறது; நீங்கள் இருக்கும் தளம் எவ்வளவு வேகமானது, பாதுகாப்பானது, அங்கே உங்களை யார் கண்காணிக்கிறார்கள் என்பதை ஒரே கிளிக்கில் காட்டுகிறது.

மேலும் வேகம், மேலும் இலகு
விளம்பர ஸ்கிரிப்ட்களும் டிராக்கர்களும் இல்லாமல் பக்கங்கள் வேகமாக ஏற்றப்படுகின்றன, மொபைல் டேட்டாவும் பேட்டரியும் குறைவாகச் செலவாகின்றன. தடுப்பதை உலாவியே செய்கிறது, எனவே நீட்டிப்பு எதையும் மெதுவாக்காது.

மேலும் பாதுகாப்பு
• அறியப்பட்ட மோசடி, ஃபிஷிங், மால்வேர் தளங்களைத் தடுக்கிறது.
• குக்கீ ஒப்புதல் பாப்-அப்களை மறைக்கிறது.
• உங்கள் மொழிகளுக்கான பிராந்திய வடிகட்டிப் பட்டியல்கள் தானாக இயக்கப்படுகின்றன.

தளச் சரிபார்ப்பு
• 10-க்கு மதிப்பெண்: வேகம், பக்க அளவு, பாதுகாப்பு, தனியுரிமை.
• பக்கத்தில் யார் தரவைச் சேகரிக்கிறார்கள், எது தடுக்கப்பட்டது.
• HTTPS, பாதுகாப்புத் தலைப்புகள், தொழில்நுட்பங்கள், ஹோஸ்டிங்.
• அறிக்கையைப் படமாகவோ உரையாகவோ பகிரலாம்.
```
