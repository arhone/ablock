# ABlock - 廣告封鎖與網站檢測

Название и краткое описание берутся из `src/_locales/zh_TW/messages.json` (`extName`, `extDescription`), в консоли не вводятся.
В консоль вставляется текст из блока «Описание»; скриншоты — `../img/en/`.

**Название:** ABlock - 廣告封鎖與網站檢測

**Краткое описание:** 封鎖廣告和追蹤器，網頁載入更快、更省流量。檢測任何網站的速度、安全性和追蹤情況。

## Описание

```text
ABlock 可封鎖廣告和追蹤器，並一鍵顯示你正在瀏覽的網站有多快、多安全，以及誰在那裡追蹤你。

更快、更輕
沒有廣告指令碼和追蹤器，網頁載入更快，也更省行動數據和電量。封鎖由瀏覽器本身完成，因此擴充功能不會拖慢任何東西。

更安全
• 封鎖已知的詐騙、網路釣魚和惡意軟體網站。
• 隱藏 Cookie 同意彈出視窗。
• 依你的語言自動啟用地區性過濾清單。

網站檢查
• 10 分制評分：速度、網頁大小、安全性和隱私。
• 誰在網頁上收集資料，以及封鎖了哪些內容。
• HTTPS、安全標頭、使用技術和主機代管。
• 以圖片或文字分享報告。

隱私
一切都在你的瀏覽器中執行。沒有分析工具、沒有帳號、沒有自有伺服器。

如果某個網站無法正常運作，只要關閉該網站的防護即可。

開放原始碼：https://github.com/arhone/ablock
意見回饋：https://github.com/arhone/ablock/issues
支持這個專案：https://boosty.to/a.arh/donate
```
