# ABlock - ആഡ് ബ്ലോക്കറും സൈറ്റ് പരിശോധനയും

Название и краткое описание берутся из `src/_locales/ml/messages.json` (`extName`, `extDescription`), в консоли не вводятся.
В консоль вставляется текст из блока «Описание»; скриншоты — `../img/en/`.

**Название:** ABlock - ആഡ് ബ്ലോക്കറും സൈറ്റ് പരിശോധനയും

**Краткое описание:** പരസ്യങ്ങളും ട്രാക്കറുകളും തടയുന്നു: പേജുകൾ വേഗത്തിൽ, ഡാറ്റ കുറവ്. ഏത് സൈറ്റിന്റെയും വേഗവും സുരക്ഷയും പരിശോധിക്കുന്നു.

## Описание

```text
ABlock പരസ്യങ്ങളും ട്രാക്കറുകളും തടയുന്നു; നിങ്ങൾ ഉള്ള സൈറ്റ് എത്ര വേഗമുള്ളതും സുരക്ഷിതവുമാണെന്നും അവിടെ നിങ്ങളെ ആരാണ് ട്രാക്ക് ചെയ്യുന്നതെന്നും ഒറ്റ ക്ലിക്കിൽ കാണിക്കുന്നു.

കൂടുതൽ വേഗം, കൂടുതൽ ഭാരം കുറവ്
പരസ്യ സ്ക്രിപ്റ്റുകളും ട്രാക്കറുകളും ഇല്ലാതെ പേജുകൾ വേഗത്തിൽ ലോഡ് ആകുന്നു, മൊബൈൽ ഡാറ്റയും ബാറ്ററിയും കുറച്ചേ ചെലവാകൂ. തടയുന്നത് ബ്രൗസർ തന്നെയാണ്, അതിനാൽ എക്സ്റ്റൻഷൻ ഒന്നിനെയും മന്ദഗതിയിലാക്കുന്നില്ല.

കൂടുതൽ സുരക്ഷിതം
• അറിയപ്പെടുന്ന തട്ടിപ്പ്, ഫിഷിംഗ്, മാൽവെയർ സൈറ്റുകൾ തടയുന്നു.
• കുക്കി സമ്മത പോപ്പ്-അപ്പുകൾ മറയ്ക്കുന്നു.
• നിങ്ങളുടെ ഭാഷകൾക്കുള്ള പ്രാദേശിക ഫിൽട്ടർ ലിസ്റ്റുകൾ സ്വയമേവ ഓണാകുന്നു.

സൈറ്റ് പരിശോധന
• 10-ൽ സ്കോർ: വേഗം, പേജിന്റെ ഭാരം, സുരക്ഷ, സ്വകാര്യത.
• പേജിൽ ആരാണ് ഡാറ്റ ശേഖരിക്കുന്നത്, എന്താണ് തടഞ്ഞത്.
• HTTPS, സുരക്ഷാ ഹെഡറുകൾ, സാങ്കേതികവിദ്യകൾ, ഹോസ്റ്റിംഗ്.
• റിപ്പോർട്ട് ചിത്രമായോ ടെക്സ്റ്റായോ പങ്കിടാം.

സ്വകാര്യത
എല്ലാം നിങ്ങളുടെ ബ്രൗസറിൽ തന്നെ പ്രവർത്തിക്കുന്നു. അനലിറ്റിക്സ് ഇല്ല, അക്കൗണ്ടുകൾ ഇല്ല, ഞങ്ങളുടെ സ്വന്തം സെർവറുകൾ ഇല്ല.

ഏതെങ്കിലും സൈറ്റ് ശരിയായി പ്രവർത്തിക്കുന്നില്ലെങ്കിൽ, ആ സൈറ്റിന് മാത്രം സംരക്ഷണം ഓഫ് ചെയ്യുക.
```
