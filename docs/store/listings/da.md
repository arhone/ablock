# ABlock - Reklameblokering og webstedstjek

Название и краткое описание берутся из `src/_locales/da/messages.json` (`extName`, `extDescription`), в консоли не вводятся.
В консоль вставляется текст из блока «Описание»; скриншоты — `../img/en/`.

**Название:** ABlock - Reklameblokering og webstedstjek

**Краткое описание:** Blokerer reklamer og trackere: hurtigere sider, mindre data. Tjekker hastighed, sikkerhed og sporing på ethvert websted.

## Описание

```text
ABlock blokerer reklamer og trackere og viser med ét klik, hvor hurtigt og sikkert det websted, du er på, er, og hvem der sporer dig der.

HURTIGERE OG LETTERE
Uden reklamescripts og trackere indlæses sider hurtigere og bruger mindre mobildata og batteri. Det er browseren selv, der blokerer, så udvidelsen gør intet langsommere.

SIKRERE
• Blokerer kendte svindel-, phishing- og malwarewebsteder.
• Skjuler cookie-bannere.
• Regionale filterlister slås automatisk til for dine sprog.

WEBSTEDSTJEK
• Karakter ud af 10: hastighed, sidevægt, sikkerhed og privatliv.
• Hvem der indsamler data på siden, og hvad der blev blokeret.
• HTTPS, sikkerhedsheadere, teknologier og hosting.
• Del rapporten som billede eller tekst.

PRIVATLIV
Alt kører i din browser. Ingen analyse, ingen konti, ingen egne servere.

Hvis et websted ikke virker, så slå beskyttelsen fra kun for det websted.

Åben kildekode: https://github.com/arhone/ablock
Feedback: https://github.com/arhone/ablock/issues
Støt projektet: https://boosty.to/a.arh/donate
```
