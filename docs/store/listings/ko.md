# ABlock - 광고 차단 및 사이트 점검

Название и краткое описание берутся из `src/_locales/ko/messages.json` (`extName`, `extDescription`), в консоли не вводятся.
В консоль вставляется текст из блока «Описание»; скриншоты — `../img/en/`.

**Название:** ABlock - 광고 차단 및 사이트 점검

**Краткое описание:** 광고와 추적기를 차단해 페이지를 더 빠르고 가볍게 합니다. 모든 사이트의 속도, 보안, 추적을 점검합니다.

## Описание

```text
ABlock은 광고와 추적기를 차단하고, 지금 보고 있는 사이트가 얼마나 빠르고 안전한지, 누가 그곳에서 나를 추적하는지 클릭 한 번으로 보여 줍니다.

더 빠르고 가볍게
광고 스크립트와 추적기가 없으면 페이지가 더 빨리 열리고 모바일 데이터와 배터리를 덜 사용합니다. 차단은 브라우저가 직접 하므로 확장 프로그램이 아무것도 느리게 만들지 않습니다.

더 안전하게
• 알려진 사기, 피싱, 악성코드 사이트를 차단합니다.
• 쿠키 동의 팝업을 숨깁니다.
• 사용하는 언어에 맞는 지역 필터 목록이 자동으로 켜집니다.

사이트 점검
• 10점 만점 점수: 속도, 페이지 용량, 보안, 개인정보 보호.
• 페이지에서 누가 데이터를 수집하는지, 무엇이 차단되었는지.
• HTTPS, 보안 헤더, 사용 기술, 호스팅.
• 보고서를 이미지나 텍스트로 공유.

개인정보 보호
모든 것이 브라우저 안에서 작동합니다. 분석 도구도, 계정도, 자체 서버도 없습니다.

사이트가 제대로 작동하지 않으면 그 사이트에서만 보호를 끄세요.

의견 보내기: https://github.com/arhone/ablock/issues
프로젝트 후원: https://boosty.to/a.arh/donate
```
