# ABlock - Reklameblokkering og nettstedsjekk

Название и краткое описание берутся из `src/_locales/no/messages.json` (`extName`, `extDescription`), в консоли не вводятся.
В консоль вставляется текст из блока «Описание»; скриншоты — `../img/en/`.

**Название:** ABlock - Reklameblokkering og nettstedsjekk

**Краткое описание:** Blokkerer reklame og sporere: raskere sider, mindre data. Sjekker hastighet, sikkerhet og sporing på alle nettsteder.

## Описание

```text
ABlock blokkerer reklame og sporere og viser med ett klikk hvor raskt og trygt nettstedet du er på, er, og hvem som sporer deg der.

RASKERE OG LETTERE
Uten reklameskript og sporere lastes sider raskere og bruker mindre mobildata og batteri. Det er nettleseren selv som blokkerer, så utvidelsen gjør ingenting tregere.

TRYGGERE
• Blokkerer kjente svindel-, phishing- og skadevarenettsteder.
• Skjuler informasjonskapsel-bannere.
• Regionale filterlister slås på automatisk for språkene dine.

NETTSTEDSSJEKK
• Karakter av 10: hastighet, sidevekt, sikkerhet og personvern.
• Hvem som samler inn data på siden, og hva som ble blokkert.
• HTTPS, sikkerhetshoder, teknologier og hosting.
• Del rapporten som bilde eller tekst.

PERSONVERN
Alt kjører i nettleseren din. Ingen analyse, ingen kontoer, ingen egne servere.

Hvis et nettsted slutter å fungere, slå av beskyttelsen bare for det nettstedet.

Åpen kildekode: https://github.com/arhone/ablock
Tilbakemelding: https://github.com/arhone/ablock/issues
Støtt prosjektet: https://boosty.to/a.arh/donate
```
