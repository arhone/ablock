Приватность

ABlock обрабатывает данные о сайтах в браузере. Здесь описано, какие данные нужны расширению, где они хранятся и когда возникают сетевые запросы.

Разрешения и доступ к сайтам

Обязательные разрешения указаны в манифесте расширения:

declarativeNetRequest
Блокировка рекламы, трекеров и опасных адресов по встроенным правилам. Для сайтов, где вы отключили защиту, создаётся правило-исключение.
scripting
Вставка скриптов и CSS для удаления рекламы, скрытия баннеров и сбора сведений для отчёта: технологий, загрузки, разметки и других показателей страницы.
activeTab
Доступ к текущей вкладке при открытии окна расширения — чтобы прочитать адрес и получить данные страницы для отчёта.
storage
Хранение настроек, исключений, заметок и статистики в браузере. Подробности — ниже.
Доступ к отдельным сайтам
Видеохостинги и соцсети: YouTube, VK, OK и другие. Скрипты и стили убирают рекламу в плеерах, лентах и на страницах этих сайтов.

Для отчёта ABlock читает в браузере cookie страницы, доступные JavaScript (без HttpOnly). По признакам вроде PHPSESSID и wordpress_ он определяет технологии сайта, а для проверки безопасности находит до трёх названий cookie, похожих на вход в аккаунт. Это предположение по названию. Значения cookie не сохраняются расширением и никуда им не передаются.

Необязательные разрешения

При включении расширенного режима ABlock запрашивает webRequest и доступ ко всем адресам (<all_urls>). Это позволяет получать IP и выбранные заголовки ответа сервера, учитывать форматы изображений и заблокированные запросы. Доступ ко всем сайтам также нужен для скрытия окон про cookie и пустых мест под рекламу и увеличения буфера сведений о загруженных файлах страницы.

Расширенный режим выключается кнопкой внизу раскрытой оценки. При этом расширение снимает оба разрешения. Отключение режима само по себе не удаляет сохранённую статистику.

browsingData запрашивается отдельно при первом использовании корзины «Очистить данные сайта». По подтверждению ABlock удаляет cookie, кэш, Cache Storage, файловые системы, IndexedDB, localStorage, service worker и WebSQL для текущего сайта и перезагружает вкладку без кэша. Для хранилищ учитываются HTTP- и HTTPS-адреса с www. и без него; cookie браузер удаляет для домена. Это может привести к выходу из аккаунта на сайте.

Что хранится в браузере

Расширение использует chrome.storage.local для следующих данных. chrome.storage.sync в коде не используется: эти данные не отправляются расширением в синхронизацию браузера.

Настройки защиты
aBlockStorage — включена ли защита (status); aBlockSettings — настройка скрытия окон про cookie (cookies); aBlockAllowed — список доменов, для которых защита отключена.
Язык и оформление
aBlockLang — выбранный язык окна; aBlockTheme — выбранная тема; aBlockDark — признак тёмной темы для цветов счётчика на значке расширения.
Заметки
aBlockNotes — ваши тексты, привязанные к имени сайта без начального www..
Общая статистика
aBlockStats — три числа: количество заблокированных запросов (requests), примерный объём сэкономленного трафика (bytes) и время начала подсчёта (since). Экономия оценивается по среднему размеру запроса каждого типа. Эта общая статистика не содержит списка посещённых сайтов.
Отметки для напоминаний
aBlockInstalled — время установки, а для ранее установивших расширение — первого обновления с этой функцией. aBlockRated и aBlockAsked — время нажатия кнопки или закрытия просьбы оценить расширение и поддержать проект. Это отметки показа просьб, а не подтверждение оценки или платежа.

Временные данные

В chrome.storage.session расширенный режим сохраняет aBlockTabs: по вкладкам — имя сайта, IP сервера, выбранные заголовки ответа, счётчики форматов изображений, оценку сэкономленного трафика и счётчики заблокированных адресов. Для последних записываются домен и до 40 символов пути без параметров запроса; на вкладку — не более 300 таких записей. Данные вкладки удаляются при её закрытии и заменяются при получении ответа новой основной страницы. Сессионное хранилище существует до закрытия браузера.

aBlockClear в том же хранилище — временное поручение очистить сайт: ID вкладки, её полный URL и время нажатия. Оно нужно, если окно расширения закроется во время запроса разрешения. При выдаче разрешения поручение удаляется и выполняется, только если прошло меньше двух минут; при отказе удаляется.

Как изменить или удалить данные

Настройки защиты, языка и темы меняются в окне расширения. Чтобы убрать сайт из исключений, включите защиту для него. Чтобы удалить заметку, откройте её, очистите текст и сохраните клавишей Enter.

Общей кнопки удаления всех настроек и статистики в интерфейсе сейчас нет. Корзина «Очистить данные сайта» удаляет данные самого сайта, а не настройки ABlock. Для удаления всех данных расширения удалите ABlock через страницу расширений браузера: chrome://extensions в Chrome или browser://extensions в Яндекс Браузере.

Какие запросы делает расширение

При открытии окна ABlock запускает проверку страницы. Она запрашивает три файла у открытого сайта: /robots.txt, /llms.txt и /.well-known/security.txt. Адреса этих файлов строятся от адреса открытого сайта. Они нужны для сведений о правилах для поисковых и ИИ-ботов и наличии контакта по безопасности. Запросы выполняются без учётных данных (credentials: omit), с тайм-аутом две секунды и следуют перенаправлениям сервера, в том числе на другой адрес.

Остальные вызовы fetch читают файлы из установленного расширения: переводы, справочники компаний и хостингов, описание наборов правил, собственные и сторонние косметические фильтры, а при создании картинки отчёта — её локальные изображения и фон. Они не скачиваются с серверов проекта. IP сервера берётся из событий браузера, хостинг определяется по базе внутри расширения.

В скрипте для VK есть перехват fetch страницы: проверки блокировщика методом HEAD к четырём рекламным и счётным адресам получают искусственный успешный ответ; остальные вызовы передаются исходной функции сайта. Это обработка запросов сайта, а не отправка данных расширением.

Других самостоятельных сетевых запросов в коде расширения нет: оно не обращается к DoH, whois, сторонним API или аналитике и не отправляет настройки, заметки и статистику на сервер. Вызовов XMLHttpRequest нет. Списки фильтров и база хостингов поставляются в составе расширения.

Ссылки и «Поделиться»

По вашему нажатию открываются Chrome Web Store, Boosty, Telegram и GitHub. Это переходы на внешние сайты, а не фоновая передача данных ABlock.

Меню «Поделиться» может открыть выбранный вами сервис. В русском интерфейсе это Telegram, VK, OK, Max и X; в других языках набор отличается. В ссылку подставляются ссылка на расширение в магазине и текст отчёта или описание расширения — в зависимости от выбранного действия и сервиса. Некоторые сервисы получают только ссылку. Отчёт может содержать имя проверяемого сайта, оценку, сведения о сервере и замечания проверки.

Картинку или текст отчёта также можно скопировать, картинку — сохранить файлом или передать через системное меню «Поделиться», если оно доступно в браузере. Вы сами выбираете получателя. Переходы и отправленные вами материалы обрабатываются соответствующими внешними сервисами.
