# ABlock

Расширение для Chrome и Яндекс Браузера (Manifest V3): блокирует рекламу, трекеры и опасные сайты и в один клик показывает отчёт о сайте — скорость, безопасность, слежка, технологии, хостинг. Код — в `src/` без сборки (чистые JS, CSS, HTML), 53 языка в `src/_locales/`. Подробно — `README.md`.

## Для агентов
- Знания о проекте: `.agents/docs/` (начать с `README.md`).
- Скиллы проекта: `.agents/skills/` (для Claude — через `.claude/skills`).
- Команда воркеров и порядок работы: `.agents/workers/AGENTS.md` (не в git); задачи — `.agents/tasks/`.
- `.agents/local/` — входящие и черновики автора, не в git.
- Главная сессия подсказывает автору, когда чистить контекст (каждый шаг перечитывает весь разговор — длинная сессия дорожает): фоновых задач нет и блок работы закончен (влито, решения записаны) — «можно `/clear`, потом `/orchestrator`»; в фоне кто-то работает, а разговор уже длинный — «можно `/compact`» (после `/clear` отчёт фонового воркера не дойдёт). Перед подсказкой всё состояние — в задачах и `orchestrator/CONTEXT.md`.

## Ограничения
- Отвечать и писать по-русски (тексты интерфейса — во всех локалях).
- Ветки: main и beta не трогать; alpha — рабочая, но без слова автора в неё не коммитить и не вливать. push — никогда.
- Коммит — только по слову автора «коммить» (воркеры коммитят в свою ветку `work/*`). Без Co-Authored-By и любой атрибуции ИИ.
- Данные не покидают браузер: расширение не делает внешних запросов (DoH, whois, сторонние API). Сайты не проверяются на уязвимости (.git, .env и т. п.) — только то, что браузер уже знает, плюс robots.txt, llms.txt, .well-known/security.txt.
- Новых разрешений не добавлять, `src/manifest.json` без автора не менять.
- Списки фильтров и `src/content/cookies.css` — чужие (GPL, CC BY-SA): атрибуцию не убирать.
- Поддерживаются только Chrome и Яндекс Браузер. В промо — без Meta (Facebook, Instagram).
