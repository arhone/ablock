# Каталог ИИ-ботов (схема 1)

`ai-bots.json` — локальные метаданные, не код обхода. Ссылки не загружаются расширением.
Текущий `AI_BOTS` и строка «Правила для ИИ-ботов» пока не меняются.
Другие справочники описаны в корневом README; DEVELOPMENT.md в проекте нет.

Корень: `{ "schemaVersion": 1, "bots": [...] }`. Все поля записи обязательны:

| Поле | Контракт |
| --- | --- |
| `id` | Стабильный уникальный ASCII slug; не менять при переименовании продукта. |
| `name`, `operator` | Имя продукта и оператор, строки; не локализуются. Для неподтверждённой записи оператор — прежняя атрибуция, не результат проверки. |
| `tokens` | Только подтверждённые действующие robots.txt product tokens, без версии и полного HTTP User-Agent. Массив может быть пустым. Несколько токенов одной записи означают одного бота, не несколько ботов. |
| `category` | Только `training` (обучение), `search` (поиск/поисковые ответы), `user` (получение по запросу пользователя), `mixed` (смешанное, иное или неподтверждённое назначение). Это редакционная классификация заявленного назначения, не доказательство реального поведения. |
| `type` | `crawler` — программа, сама получающая страницы (включая user fetcher, а не только автоматический обход); `control` — управляющий токен использования данных без самостоятельного обхода; `null` — тип не подтверждён. |
| `historicalTokens` | Подтверждённые прежние robots-токены/имена, более не выдаваемые за действующие. Сейчас пусты: подтверждения переименований не получены. Не использовать как действующие aliases. |
| `unverifiedTokens` | Имена из прежнего списка или кандидаты, чей текущий статус не подтверждён первичным источником. Не означают ни действующий, ни достоверно исторический токен. Не использовать как действующие aliases. |
| `source` | HTTPS URL официального первичного источника; при `unverified` — страница оператора, где искали подтверждение, а не доказательство токена. |
| `sourceStatus` | `verified` — действующие токены и назначение проверены; `unverified` — подтверждение не получено, `tokens` пуст, `category` равна `mixed`, `type` равен `null`. |
| `checkedAt` | Дата проверки/попытки проверки `YYYY-MM-DD` (2026-10-30). Не дата публикации источника. |
| `notes` | Причина классификации, ограничения источника и существенные особенности; редакционные метаданные, не готовый текст интерфейса. |

Для 2б-9: индексировать **только `tokens`**, сравнивать регистронезависимо, возвращать стабильный `id`.
Токен однозначен во всех трёх массивах всего каталога с учётом регистра.
Исторические/неподтверждённые имена при необходимости показывать отдельно как неизвестные,
без переноса категории действующего продукта. Отсутствие записи/токена не означает разрешение.
Не выводить из категории, что оператор обязательно соблюдает robots.txt: user fetchers могут
не применять правила. Наличие правила не доказывает запрет всего сайта или отказ от обучения.
Особые fallback-семантики Applebot/Amzn-SearchBot не реализованы этим справочником.

## Проверка и неполнота

Node без зависимостей:

```sh
node /srv/arhone/ablock/.agents/workers/developers/rada/files/stage2b-ai-catalog/check.cjs /srv/arhone/ablock.wt/stage2b-ai-catalog
npm run lint
```

Справочник охватывает все 16 имён старого AI_BOTS: 11 как действующие, 5 как
неподтверждённые (`Claude-Web`, `anthropic-ai`, `Bytespider`, `cohere-ai`, `meta-externalagent`).
Дополнены основные разделённые поисковые и пользовательские агенты операторов.
Каталог не претендует на полный перечень всех роботов интернета.

Официальная страница Meta отвечала 429; оба meta-external* оставлены неподтверждёнными.
Документация Bytespider не получена; назначение не приписано по сторонним каталогам.
Текущая страница Anthropic не подтверждает старые Claude-Web/anthropic-ai и их преемников.
Cohere явно сообщает об отсутствии текущих ботов для сбора обучающих данных;
условный пример Coherebot не включён в действующие токены.
Google-Extended — mixed: обучение **и** grounding, Applebot-Extended — training.
Applebot/Amazonbot/CCBot/Diffbot — mixed: назначение шире одной узкой категории.
YandexAdditional/YandexAdditionalBot — один управляющий продукт для поисковых ответов.
OAI-AdsBot — mixed: проверка рекламы не соответствует трём узким категориям.
Проверялась документация, а не фактическое соблюдение правил роботами.
